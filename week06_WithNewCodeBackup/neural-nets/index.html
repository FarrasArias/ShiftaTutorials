Sound Synthesis

Sound is vibration. When an object vibrates: a guitar string, a speaker cone, your vocal cords: it pushes and pulls the air molecules around it, creating waves of high and low pressure that travel outward. When those pressure waves reach your ear, your eardrum vibrates in sympathy and your brain interprets the pattern as sound.

This means sound is fundamentally physical: it's a pattern of pressure changes over time. And because pressure can be measured as a number, sound is also fundamentally data.

The Sine Wave

The simplest possible sound is a sine wave: a smooth, periodic oscillation described by:

\[y(t) = A \times \sin(2\pi f t)\]

where \(A\) is the amplitude (how loud: the height of the wave), \(f\) is the frequency (how many cycles per second, measured in Hertz), and \(t\) is time in seconds.

A sine wave at 440 Hz completes 440 full cycles every second. We hear this as the note A above middle C: the standard tuning reference used by orchestras worldwide.

Key relationships:

  • Frequency → pitch: higher frequency = higher pitch. Doubling the frequency raises the pitch by one octave: 440 Hz is A4, 880 Hz is A5.
  • Amplitude → loudness: larger amplitude = louder sound. An amplitude of 0 is silence.
  • Phase → timing: the starting point within a cycle. Phase differences become important when combining multiple waves.

Digital Audio

Computers can't store a continuous wave: they work with discrete numbers. To represent sound digitally, we sample the wave at regular intervals: we measure the pressure value thousands of times per second and store each measurement as a number.

The sample rate is how many measurements we take per second. Standard audio uses 44,100 samples per second (44.1 kHz): the same rate used on CDs. This means every second of audio is an array of 44,100 numbers.

Why 44,100? The Nyquist theorem tells us that to faithfully capture a frequency, we need to sample at at least twice that frequency. Human hearing tops out around 20,000 Hz, so we need at least 40,000 samples per second. 44,100 gives us some headroom.

\[\text{sample rate} \geq 2 \times f_{\text{max}}\]

The bit depth determines how precisely we measure each sample. 16-bit audio gives us \(2^{16} = 65,536\) possible amplitude levels. 24-bit audio gives \(2^{24} = 16,777,216\) levels: much more detail in quiet passages.

When we use p5.sound, all of this sampling and reconstruction happens behind the scenes. The Web Audio API (which p5.sound wraps) handles the conversion between the numbers in our code and the actual speaker vibrations.

Oscillators in p5.js

An oscillator is a sound source that generates a continuous periodic waveform. In p5.sound, we create one with new p5.Oscillator(type), where type is the shape of the wave:

  • 'sine': smooth and pure. Only contains the fundamental frequency. Sounds like a flute or a tuning fork.
  • 'triangle': contains odd harmonics that fall off quickly. Softer and warmer than a square wave. Sounds hollow, woody.
  • 'sawtooth': contains all harmonics (odd and even). Bright and buzzy. The classic synthesizer sound for strings and leads.
  • 'square': contains odd harmonics only. Hollow and reedy, like a clarinet or early video game music.

Here is the most basic oscillator sketch:

open example in new window

The code for this sketch:

let osc;
let isPlaying = false;

function setup() {
  createCanvas(400, 300);
  osc = new p5.Oscillator('sine');
  osc.freq(440);
  osc.amp(0);
  textAlign(CENTER, CENTER);
  textSize(18);
}

function draw() {
  background(15);
  fill(isPlaying ? '#FF4D1C' : '#555');
  text(isPlaying ? 'click to stop' : 'click to start', width / 2, height / 2);
}

function mousePressed() {
  if (!isPlaying) {
    osc.start();
    osc.amp(0.3, 0.1);
    isPlaying = true;
  } else {
    osc.amp(0, 0.3);
    isPlaying = false;
  }
}

Notice we never set the amplitude to a value instantly: we always provide a ramp time (the second argument to amp()). Jumping from 0 to 0.3 in a single sample creates a harsh click called a DC discontinuity. Fading over even 0.1 seconds eliminates this.

Frequency and Pitch

The relationship between frequency and musical pitch is logarithmic, not linear. Doubling a frequency always raises the pitch by one octave, regardless of the starting frequency:

  • A3 = 220 Hz → A4 = 440 Hz (difference: 220 Hz)
  • A4 = 440 Hz → A5 = 880 Hz (difference: 440 Hz)
  • A5 = 880 Hz → A6 = 1760 Hz (difference: 880 Hz)

Each octave covers twice as much frequency range as the one below it, but our ears perceive each step as the same size. This is why we use exponential formulas for pitch calculations rather than linear ones.

The general formula for converting a MIDI note number \(n\) to a frequency in Hz is:

\[f = 440 \times 2^{(n - 69)/12}\]

where MIDI note 69 = A4 = 440 Hz. This gives us every note on a standard piano keyboard.

Interactive Oscillator

We can use mouseX and mouseY to control pitch and amplitude in real time. Since pitch is logarithmic, we should map the mouse position exponentially: using pow(): rather than linearly:

open example in new window 
let osc;

function setup() {
  createCanvas(400, 300);
  osc = new p5.Oscillator('sine');
  osc.amp(0);
  osc.start();
  textAlign(CENTER);
  textSize(14);
}

function draw() {
  background(15);

  let minFreq = 100;
  let maxFreq = 2000;
  let freq = minFreq * pow(maxFreq / minFreq, mouseX / width);
  let amp = map(mouseY, 0, height, 0.5, 0);
  amp = constrain(amp, 0, 0.5);

  osc.freq(freq, 0.05);
  osc.amp(amp, 0.05);

  fill('#C5F74F');
  noStroke();
  let d = map(amp, 0, 0.5, 5, 150);
  circle(mouseX, mouseY, d);

  fill('#888');
  text(nf(freq, 1, 1) + ' Hz', width / 2, height - 20);
}

function mousePressed() {
  osc.start();
}

The exponential mapping minFreq * pow(maxFreq / minFreq, mouseX / width) ensures that moving the mouse the same distance always changes the pitch by the same musical interval. If we used map(mouseX, 0, width, 100, 2000) instead, the lower octaves would be crammed into a tiny sliver on the left side of the canvas.

Multiple Oscillators

Real sounds are almost never a single sine wave. A violin playing A4 produces a fundamental at 440 Hz plus overtones at 880, 1320, 1760 Hz and beyond, each at different amplitudes. The recipe of overtones is what gives each instrument its unique character: its timbre.

We can start building richer sounds by layering oscillators:

open example in new window 
let osc1, osc2;

function setup() {
  createCanvas(400, 300);
  osc1 = new p5.Oscillator('sine');
  osc2 = new p5.Oscillator('sine');
  osc1.amp(0);
  osc2.amp(0);
  osc1.freq(440);
  osc2.freq(443);
  textAlign(CENTER, CENTER);
  textSize(16);
}

function draw() {
  background(15);
  fill('#f0ece4');
  text('click to hear beating\n440 Hz + 443 Hz', width / 2, height / 2);
}

function mousePressed() {
  osc1.start();
  osc2.start();
  osc1.amp(0.2, 0.1);
  osc2.amp(0.2, 0.1);
}

function mouseReleased() {
  osc1.amp(0, 0.3);
  osc2.amp(0, 0.3);
}

When two oscillators are close in frequency but not identical, they create beating: a pulsing effect where the combined amplitude rises and falls. The beat frequency equals the difference between the two frequencies. Here, 443 − 440 = 3 beats per second. This is how piano tuners work: they listen for beats to disappear as two strings approach the same pitch.

This phenomenon: interference: is fundamental to understanding how waves combine. When the peaks align (constructive interference), the sound gets louder. When a peak meets a trough (destructive interference), they cancel out. The result is that pulsing, tremolo-like effect.
