Scales & Frequency

In the previous tutorials we generated tones at arbitrary frequencies. But music is built on scales: specific collections of pitches chosen for their relationships to each other. Understanding how scales are constructed mathematically lets us build generative systems that sound musical rather than random.

Intervals and Frequency Ratios

When two notes sound "good" together: when we perceive consonance: it's because their frequencies form simple ratios. This was discovered by Pythagoras around 500 BCE and remains the foundation of tuning theory.

The simplest ratios produce the most consonant intervals:

  • Octave: \(2:1\): frequencies 220 Hz and 440 Hz. So perfectly consonant that we consider them "the same note."
  • Perfect fifth: \(3:2\): frequencies 220 Hz and 330 Hz. The most consonant interval after the octave. The backbone of Western harmony.
  • Perfect fourth: \(4:3\): frequencies 220 Hz and 293.3 Hz.
  • Major third: \(5:4\): frequencies 220 Hz and 275 Hz. Warm and bright.
  • Minor third: \(6:5\): frequencies 220 Hz and 264 Hz. Darker, melancholic.

The more complex the ratio, the more dissonant (tense, rough) the interval sounds. This is because complex ratios create interference patterns that our ears detect as "beating" or roughness.

Just Intonation: Pure Ratios

If we build a scale using only pure frequency ratios, we get just intonation. A just major scale starting on 220 Hz:

DegreeRatioFrequencyInterval name
1 (root)\(1:1\)220.0 HzUnison
2\(9:8\)247.5 HzMajor second
3\(5:4\)275.0 HzMajor third
4\(4:3\)293.3 HzPerfect fourth
5\(3:2\)330.0 HzPerfect fifth
6\(5:3\)366.7 HzMajor sixth
7\(15:8\)412.5 HzMajor seventh
8\(2:1\)440.0 HzOctave

Just intonation sounds beautiful in one key. The problem: if you try to transpose to a different starting note, the ratios between notes change and some intervals become out of tune. This is the comma problem that plagued Western music for centuries.

open example in new window 
let osc, env;
let baseFreq = 220;
let justRatios = [1, 9/8, 5/4, 4/3, 3/2, 5/3, 15/8, 2];

function setup() {
  createCanvas(400, 300);
  osc = new p5.Oscillator('triangle');
  osc.amp(0);
  osc.start();

  env = new p5.Envelope();
  env.setADSR(0.01, 0.2, 0.3, 0.3);
  env.setRange(0.4, 0);

  textAlign(CENTER, CENTER);
  textSize(14);
}

function draw() {
  background(15);
  fill('#f0ece4');
  text('Just Intonation Major Scale', width / 2, 20);
  text('press keys 1-8 to play scale degrees', width / 2, height - 20);

  for (let i = 0; i < justRatios.length; i++) {
    let x = map(i, 0, justRatios.length - 1, 50, width - 50);
    let freq = baseFreq * justRatios[i];
    fill(i === 0 || i === 7 ? '#FF4D1C' : '#C5F74F');
    rect(x - 15, 80, 30, 150, 4);
    fill('#888');
    text(nf(freq, 1, 1), x, 260);
  }
}

function keyPressed() {
  let index = int(key) - 1;
  if (index >= 0 && index < justRatios.length) {
    osc.freq(baseFreq * justRatios[index]);
    env.play(osc);
  }
}

Equal Temperament: The Compromise

The solution that modern Western music settled on is 12-tone equal temperament (12-TET). Instead of using pure ratios, we divide the octave into 12 exactly equal steps on a logarithmic scale. Each step (a semitone) multiplies the frequency by:

\[r = 2^{1/12} \approx 1.05946\]

The frequency of note \(k\) semitones above a base frequency \(f_0\) is:

\[f_k = f_0 \times 2^{k/12}\]

This means:

  • The "equal-tempered fifth" (7 semitones) has a ratio of \(2^{7/12} \approx 1.4983\), very close to the pure \(3:2 = 1.5\).
  • The "equal-tempered major third" (4 semitones) has a ratio of \(2^{4/12} \approx 1.2599\), noticeably different from the pure \(5:4 = 1.25\).

The tradeoff: no interval is perfectly pure, but every key sounds equally good (or equally bad). This is why a piano can play in any key without retuning.

open example in new window 
let osc, env;
let baseFreq = 261.63;
let noteNames = ['C','C#','D','D#','E','F','F#','G','G#','A','A#','B'];

function setup() {
  createCanvas(500, 300);
  osc = new p5.Oscillator('sine');
  osc.amp(0);
  osc.start();

  env = new p5.Envelope();
  env.setADSR(0.01, 0.15, 0.2, 0.3);
  env.setRange(0.35, 0);

  textAlign(CENTER, CENTER);
  textSize(12);
}

function draw() {
  background(15);
  fill('#f0ece4');
  text('12-TET Chromatic Scale:  click a key', width / 2, 20);

  for (let i = 0; i < 12; i++) {
    let x = map(i, 0, 11, 40, width - 40);
    let isBlack = [1, 3, 6, 8, 10].includes(i);

    fill(isBlack ? '#333' : '#f0ece4');
    rect(x - 16, 50, 32, 160, 4);

    fill(isBlack ? '#aaa' : '#333');
    text(noteNames[i], x, 230);

    let freq = baseFreq * pow(2, i / 12);
    fill('#888');
    text(nf(freq, 1, 1), x, 250);
  }
}

function mousePressed() {
  for (let i = 0; i < 12; i++) {
    let x = map(i, 0, 11, 40, width - 40);
    if (abs(mouseX - x) < 16 && mouseY > 50 && mouseY < 210) {
      let freq = baseFreq * pow(2, i / 12);
      osc.freq(freq);
      env.play(osc);
      break;
    }
  }
}

Microtonal Tuning: N-TET

There's nothing sacred about dividing the octave into 12 parts. The general formula for N-tone equal temperament (N-TET) is:

\[f_k = f_0 \times 2^{k/N}\]

Different values of \(N\) produce different trade-offs between the available intervals:

  • 19-TET: 19 steps per octave. The major third (\(2^{6/19} \approx 1.2447\)) is much closer to the pure \(5:4 = 1.25\) than 12-TET's version. The fifth is slightly narrow. Used by some adventurous composers and microtonal guitarists.
  • 31-TET: 31 steps. Excellent approximations of both thirds and fifths. The Dutch physicist Christiaan Huygens advocated for this tuning in the 1600s.
  • 53-TET: 53 steps. Nearly indistinguishable from just intonation for most intervals. Turkish classical music theory uses a 53-division system.
  • 24-TET: quarter-tones. Used in Arabic maqam music and some 20th-century Western compositions.

In each case, we pick a subset of the N available steps to form a scale, just as we pick 7 notes from 12 to form a major scale in 12-TET.

open example in new window 
let osc, env;
let baseFreq = 220;
let N = 19;
let scaleSteps = [0, 3, 6, 8, 11, 14, 17, 19];

function setup() {
  createCanvas(500, 350);
  osc = new p5.Oscillator('triangle');
  osc.amp(0);
  osc.start();

  env = new p5.Envelope();
  env.setADSR(0.01, 0.2, 0.3, 0.3);
  env.setRange(0.35, 0);

  textAlign(CENTER, CENTER);
  textSize(12);
}

function draw() {
  background(15);
  fill('#f0ece4');
  text(N + '-TET Scale:  click a bar to play', width / 2, 20);
  text('press UP/DOWN to change N (divisions of octave)', width / 2, height - 15);

  for (let i = 0; i < scaleSteps.length; i++) {
    let x = map(i, 0, scaleSteps.length - 1, 50, width - 50);
    let freq = baseFreq * pow(2, scaleSteps[i] / N);
    let ratio = pow(2, scaleSteps[i] / N);
    let barH = map(freq, baseFreq, baseFreq * 2, 40, 200);

    fill('#FF4D1C');
    rect(x - 18, height - 50 - barH, 36, barH, 3);

    fill('#C5F74F');
    text('step ' + scaleSteps[i], x, height - 50 - barH - 15);

    fill('#888');
    text(nf(freq, 1, 1) + ' Hz', x, height - 38);
  }

  fill('#4FC5F7');
  text('N = ' + N, width / 2, 45);
}

function mousePressed() {
  for (let i = 0; i < scaleSteps.length; i++) {
    let x = map(i, 0, scaleSteps.length - 1, 50, width - 50);
    if (abs(mouseX - x) < 20) {
      let freq = baseFreq * pow(2, scaleSteps[i] / N);
      osc.freq(freq);
      env.play(osc);
      break;
    }
  }
}

function keyPressed() {
  if (keyCode === UP_ARROW) {
    N = min(N + 1, 53);
    updateScale();
  }
  if (keyCode === DOWN_ARROW) {
    N = max(N - 1, 5);
    updateScale();
  }
}

function updateScale() {
  scaleSteps = [];
  let numNotes = 8;
  for (let i = 0; i < numNotes; i++) {
    scaleSteps.push(round(i * N / (numNotes - 1)));
  }
}

Try pressing UP and DOWN arrow keys to change the number of divisions. Notice how the frequencies shift and the intervals between notes change character. Some values of N sound close to familiar Western scales; others sound alien and exotic.

Beyond the Octave: The Bohlen–Pierce Scale

Most tuning systems assume the octave (\(2:1\)) as the fundamental repeating unit. But the Bohlen–Pierce scale challenges even this assumption: it divides the tritave (\(3:1\)) into 13 equal steps instead:

\[f_k = f_0 \times 3^{k/13}\]

The step ratio is \(3^{1/13} \approx 1.08818\), compared to \(2^{1/12} \approx 1.05946\) for standard tuning. The resulting intervals have no Western equivalent: they exist in a completely different harmonic world. Music written in Bohlen–Pierce has a strange, otherworldly quality that's immediately recognizable as something different.

// Bohlen-Pierce: tritave divided into 13 steps
let bpFreq = baseFreq * pow(3, step / 13);

// Compare with standard 12-TET
let tetFreq = baseFreq * pow(2, step / 12);

The Pentatonic Scale: A Universal

Before diving deeper into microtonal systems, it's worth noting that the pentatonic scale (5 notes per octave) appears in nearly every musical culture on Earth: from Chinese traditional music to Celtic folk to West African kora to blues. In 12-TET, the major pentatonic uses steps [0, 2, 4, 7, 9], which correspond to whole-tone and minor-third intervals.

Pentatonic scales have a special property: no note clashes badly with any other. This makes them ideal for generative music: random melodies from a pentatonic scale almost always sound pleasant.

// Pentatonic scale in 12-TET
let pentatonic12 = [0, 2, 4, 7, 9];

// Approximate pentatonic in 19-TET
let pentatonic19 = [0, 3, 6, 11, 14];

// Both produce the same general "shape" of scale
// but 19-TET has subtly different interval colors
