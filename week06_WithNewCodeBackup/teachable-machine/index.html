Spectral Analysis

In the envelopes tutorial we learned that every sound is a combination of sine waves at different frequencies and amplitudes. But how do we go the other direction: given a complex sound, how do we figure out which frequencies are in it and how strong each one is?

The answer is the Fourier Transform, one of the most important mathematical tools in all of science and engineering.

Time Domain vs. Frequency Domain

There are two ways to look at any sound:

  • Time domain: amplitude as a function of time. This is what you see if you plot the raw waveform: the wiggly line that oscilloscopes show. It answers: "what is the pressure doing right now?"
  • Frequency domain: amplitude as a function of frequency. This is the spectrum: a bar chart showing how much energy is at each frequency. It answers: "what frequencies make up this sound?"

The Fourier Transform converts between these two representations. Given a time-domain signal, it produces the frequency-domain spectrum. The inverse Fourier Transform does the opposite.

Mathematically, the Fourier Transform of a signal \(x(t)\) is:

\[X(f) = \int_{-\infty}^{\infty} x(t) \, e^{-i 2\pi f t} \, dt\]

Don't worry about the integral: the key insight is conceptual: the transform decomposes a complex signal into its constituent sine waves, telling us the amplitude and phase of each frequency component.

The FFT: Fast Fourier Transform

In practice, digital audio uses the FFT (Fast Fourier Transform), an efficient algorithm that computes the discrete version of the Fourier Transform. The FFT takes a window of \(N\) audio samples and produces \(N/2\) frequency bins.

With the standard FFT size of 1024 samples at a 44,100 Hz sample rate:

  • Each frequency bin covers \(\frac{44100}{1024} \approx 43\) Hz
  • We get 512 bins, ranging from 0 Hz to ~22,050 Hz
  • Lower bins = bass frequencies, higher bins = treble frequencies

In p5.sound, the FFT is available through the p5.FFT class, which gives us two views of the sound:

let fft = new p5.FFT();

// In draw():
let waveform = fft.waveform();   // time domain: array of 1024 values, -1 to 1
let spectrum = fft.analyze();     // frequency domain: array of 1024 values, 0 to 255

Drawing a Waveform

The waveform shows the raw shape of the sound wave: what the speaker cone is physically doing at each moment. We draw it by mapping each sample to a point on the canvas:

open example in new window 
let osc, fft;

function setup() {
  createCanvas(500, 300);
  osc = new p5.Oscillator('sawtooth');
  osc.freq(220);
  osc.amp(0);

  fft = new p5.FFT();

  textAlign(CENTER);
  textSize(14);
}

function draw() {
  background(15);

  let wave = fft.waveform();

  noFill();
  stroke(79, 197, 247);
  strokeWeight(1.5);
  beginShape();
  for (let i = 0; i < wave.length; i++) {
    let x = map(i, 0, wave.length, 0, width);
    let y = map(wave[i], -1, 1, height * 0.8, height * 0.2);
    vertex(x, y);
  }
  endShape();

  noStroke();
  fill('#888');
  text('click and hold to play:  move mouse for pitch', width / 2, height - 15);
}

function mousePressed() {
  osc.start();
  osc.amp(0.3, 0.05);
}

function mouseMoved() {
  if (mouseIsPressed) {
    let freq = map(mouseX, 0, width, 80, 800);
    osc.freq(freq);
  }
}

function mouseReleased() {
  osc.amp(0, 0.2);
}

The beginShape() / vertex() / endShape() pattern draws a connected line through all 1024 points. At low frequencies you can clearly see the individual wave cycles. At higher frequencies the cycles get compressed together.

Notice how different oscillator types produce different wave shapes: a sine wave looks smooth and rounded, a sawtooth looks like a zigzag ramp, and a square wave looks like flat plateaus with sharp transitions.

Drawing a Frequency Spectrum

The spectrum shows how much energy is at each frequency: the "ingredients" of the sound. Low frequencies (bass) are on the left, high frequencies (treble) on the right:

open example in new window 
let osc, fft;

function setup() {
  createCanvas(500, 300);
  colorMode(HSB, 360, 100, 100);
  osc = new p5.Oscillator('sawtooth');
  osc.freq(220);
  osc.amp(0);

  fft = new p5.FFT(0.8, 256);
  textAlign(CENTER);
  textSize(12);
}

function draw() {
  background(0, 0, 6);

  let spectrum = fft.analyze();
  let barW = width / spectrum.length;

  noStroke();
  for (let i = 0; i < spectrum.length; i++) {
    let x = i * barW;
    let h = map(spectrum[i], 0, 255, 0, height - 40);
    let hue = map(i, 0, spectrum.length, 0, 260);
    fill(hue, 80, 80);
    rect(x, height - 30 - h, barW - 1, h);
  }

  fill(0, 0, 50);
  text('← bass                    treble →', width / 2, height - 10);
  text('click to play sawtooth at 220 Hz', width / 2, 20);
}

function mousePressed() {
  osc.start();
  osc.amp(0.3, 0.05);
}

function mouseReleased() {
  osc.amp(0, 0.2);
}

When you play the sawtooth at 220 Hz, you should see a tall spike at the fundamental (220 Hz), then progressively shorter spikes at 440, 660, 880, 1100 Hz, and so on: exactly the harmonic series. This is the FFT literally showing us the "recipe" of the sawtooth wave: all harmonics, each at amplitude \(1/n\).

A sine wave would show only a single spike. A square wave would show spikes only at odd harmonics.

FFT Parameters

The p5.FFT constructor takes two optional arguments:

let fft = new p5.FFT(smoothing, bins);
// smoothing: 0.0 to 1.0 (default 0.8)
//   Higher = smoother but slower response
//   Lower = more responsive but jittery
// bins: 16, 32, 64, 128, 256, 512, 1024 (default 1024)
//   More bins = finer frequency resolution but more data to process

The smoothing parameter is particularly important for visuals. At 0.0, the spectrum updates instantly every frame, which can look chaotic. At 0.8, each frame blends 80% of the previous value with 20% new data, creating smooth, flowing animations. Think of it as the "inertia" of the display.

Named Frequency Bands

Rather than working with the full spectrum array, p5.FFT lets us query specific frequency ranges using getEnergy():

let bass   = fft.getEnergy('bass');      // 20–140 Hz
let lowMid = fft.getEnergy('lowMid');    // 140–400 Hz
let mid    = fft.getEnergy('mid');       // 400–2600 Hz
let highMid = fft.getEnergy('highMid');  // 2600–5200 Hz
let treble = fft.getEnergy('treble');    // 5200–14000 Hz

// Or specify exact frequency range:
let sub = fft.getEnergy(20, 80);         // sub-bass

Each returns a value from 0 to 255. These named bands correspond roughly to musical and perceptual categories: bass covers kick drums and bass guitars, mid covers vocals and most melodic instruments, treble covers hi-hats and cymbals and the "air" of a recording.

open example in new window 
let osc, fft;
let waveTypes = ['sine', 'triangle', 'sawtooth', 'square'];
let currentWave = 0;

function setup() {
  createCanvas(500, 300);
  osc = new p5.Oscillator(waveTypes[currentWave]);
  osc.freq(150);
  osc.amp(0);
  fft = new p5.FFT(0.85);
  textAlign(CENTER, CENTER);
  textSize(12);
}

function draw() {
  background(15);
  fft.analyze();

  let bands = [
    { name: 'bass',    val: fft.getEnergy('bass'),    col: '#FF4D1C' },
    { name: 'lowMid',  val: fft.getEnergy('lowMid'),  col: '#FF8C42' },
    { name: 'mid',     val: fft.getEnergy('mid'),     col: '#C5F74F' },
    { name: 'highMid', val: fft.getEnergy('highMid'), col: '#4FC5F7' },
    { name: 'treble',  val: fft.getEnergy('treble'),  col: '#A77BCA' }
  ];

  let barW = width / bands.length - 20;
  for (let i = 0; i < bands.length; i++) {
    let x = map(i, 0, bands.length, 15, width - barW);
    let h = map(bands[i].val, 0, 255, 0, height - 80);

    noStroke();
    fill(bands[i].col);
    rect(x, height - 40 - h, barW, h, 4);

    fill('#888');
    text(bands[i].name, x + barW / 2, height - 20);
    text(bands[i].val, x + barW / 2, height - 50 - h);
  }

  fill('#f0ece4');
  text('wave: ' + waveTypes[currentWave] + ' | click=play | 1-4=wave type', width / 2, 15);
}

function mousePressed() {
  osc.start();
  osc.amp(0.3, 0.05);
}

function mouseReleased() {
  osc.amp(0, 0.2);
}

function keyPressed() {
  let idx = int(key) - 1;
  if (idx >= 0 && idx < waveTypes.length) {
    currentWave = idx;
    osc.setType(waveTypes[currentWave]);
  }
}

Try switching between wave types while playing. A sine wave puts all its energy in the bass/lowMid band (depending on the frequency). A sawtooth spreads energy across all bands because it contains all harmonics. This is spectral analysis making the abstract concept of timbre visible.

Combining Waveform and Spectrum

For a complete picture, we can draw both the time-domain waveform and the frequency-domain spectrum together. The waveform shows what the sound looks like; the spectrum shows what it's made of:

open example in new window 
let osc, fft;

function setup() {
  createCanvas(500, 400);
  osc = new p5.Oscillator('sawtooth');
  osc.freq(220);
  osc.amp(0);
  fft = new p5.FFT(0.8, 512);
  textAlign(CENTER);
  textSize(12);
}

function draw() {
  background(15);
  let wave = fft.waveform();
  let spectrum = fft.analyze();

  // Top half: waveform
  noFill();
  stroke(79, 197, 247);
  strokeWeight(1.2);
  beginShape();
  for (let i = 0; i < wave.length; i++) {
    let x = map(i, 0, wave.length, 0, width);
    let y = map(wave[i], -1, 1, height * 0.45, 10);
    vertex(x, y);
  }
  endShape();

  // Bottom half: spectrum
  noStroke();
  let barW = width / spectrum.length;
  for (let i = 0; i < spectrum.length; i++) {
    let h = map(spectrum[i], 0, 255, 0, height * 0.4);
    fill(255, 77, 28, spectrum[i] + 50);
    rect(i * barW, height - 30 - h, barW, h);
  }

  // Labels
  noStroke();
  fill('#555');
  text('waveform (time domain)', width / 2, height * 0.5);
  text('spectrum (frequency domain)', width / 2, height - 15);
  text('click to play', width / 2, height * 0.53);
}

function mousePressed() {
  osc.start();
  osc.amp(0.3, 0.05);
}

function mouseReleased() {
  osc.amp(0, 0.2);
}
