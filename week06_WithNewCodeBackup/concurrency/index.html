Envelopes & Timbre

In the previous tutorial we created oscillators that play continuous tones. But real sounds don't behave like that: a piano note starts suddenly and fades away; a violin note swells gradually and holds. The way a sound's amplitude changes over time is called its envelope, and it's one of the most powerful tools in synthesis.

ADSR: The Four Stages of a Note

Since the 1960s, synthesizers have used a four-stage model called ADSR to shape how each note evolves:

  • Attack: the time it takes for the sound to rise from silence to its peak amplitude. A snare drum has an attack of nearly 0 ms. A bowed cello might take 200–500 ms.
  • Decay: the time it takes to drop from the peak to the sustain level. A piano's initial hammer strike is loud, then quickly drops to a quieter ringing tone: that drop is the decay.
  • Sustain: the amplitude level held while the note is active (while a key is pressed). This is a level, not a time: it's expressed as a fraction of the peak. A pipe organ sustains at full volume; a plucked guitar has zero sustain.
  • Release: the time it takes to fade from the sustain level to silence after the note is released.

Mathematically, the envelope \(e(t)\) is a piecewise function that multiplies the oscillator's output:

\[\text{output}(t) = e(t) \times \sin(2\pi f t)\]

The envelope never changes the frequency: it only scales the amplitude. This is why a note can fade out without changing pitch.

p5.Envelope

In p5.sound, we create an envelope with new p5.Envelope() and configure it with setADSR():

open example in new window 
let osc, env;

function setup() {
  createCanvas(400, 300);
  osc = new p5.Oscillator('triangle');
  osc.amp(0);
  osc.start();

  env = new p5.Envelope();
  env.setADSR(0.05, 0.2, 0.3, 0.4);
  env.setRange(0.5, 0);

  textAlign(CENTER, CENTER);
  textSize(16);
}

function draw() {
  background(15);
  fill('#f0ece4');
  text('click to trigger a note', width / 2, height / 2);
}

function mousePressed() {
  osc.freq(random([220, 330, 440, 550, 660]));
  env.play(osc);
}

setADSR(attackTime, decayTime, sustainLevel, releaseTime) takes times in seconds and sustain as a ratio (0 to 1). setRange(peak, floor) sets the actual amplitude values that the envelope scales between.

When you call env.play(osc), the envelope runs through all four stages automatically. If you want manual control (hold a key, release a key), use env.triggerAttack(osc) and env.triggerRelease(osc) instead.

Envelope Shapes and Their Character

Different ADSR settings produce radically different sonic characters from the same oscillator:

open example in new window 
let osc, env;
let envelopes = {
  'pluck':   [0.001, 0.15, 0.0, 0.1],
  'pad':     [0.8,   0.3,  0.6, 1.0],
  'bell':    [0.001, 2.0,  0.0, 0.5],
  'swell':   [1.5,   0.1,  0.8, 0.3]
};
let currentType = 'pluck';

function setup() {
  createCanvas(400, 300);
  osc = new p5.Oscillator('triangle');
  osc.amp(0);
  osc.start();

  env = new p5.Envelope();
  env.setRange(0.4, 0);
  setEnvelope(currentType);

  textAlign(CENTER, CENTER);
  textSize(14);
}

function setEnvelope(type) {
  let e = envelopes[type];
  env.setADSR(e[0], e[1], e[2], e[3]);
  currentType = type;
}

function draw() {
  background(15);
  fill('#f0ece4');
  text('press 1-4 to change envelope, click to play', width / 2, 30);
  fill('#FF4D1C');
  text('current: ' + currentType, width / 2, height / 2);

  let labels = ['1: pluck', '2: pad', '3: bell', '4: swell'];
  fill('#888');
  for (let i = 0; i < labels.length; i++) {
    text(labels[i], width / 2, height - 80 + i * 20);
  }
}

function mousePressed() {
  osc.freq(330);
  env.play(osc);
}

function keyPressed() {
  if (key === '1') setEnvelope('pluck');
  if (key === '2') setEnvelope('pad');
  if (key === '3') setEnvelope('bell');
  if (key === '4') setEnvelope('swell');
}

Notice:

  • Pluck (0.001, 0.15, 0.0, 0.1): near-instant attack, quick decay to silence, no sustain. Guitar, harp, marimba.
  • Pad (0.8, 0.3, 0.6, 1.0): slow attack, moderate sustain, long release. Ambient, cinematic, ethereal.
  • Bell (0.001, 2.0, 0.0, 0.5): instant attack, very long decay, no sustain. The sound rings out naturally.
  • Swell (1.5, 0.1, 0.8, 0.3): very slow attack. The sound gradually fades in, like a reversed cymbal or a bowed instrument starting from nothing.

Harmonics and Timbre

Why does a violin sound different from a flute playing the same note? Both produce the same fundamental frequency, but they differ in timbre: the tonal quality or "color" of the sound.

Timbre is determined by the harmonic content: the specific mix of overtones present above the fundamental. When a string vibrates at 440 Hz, it also vibrates at 880 Hz (2nd harmonic), 1320 Hz (3rd harmonic), 1760 Hz (4th harmonic), and so on. The pattern is:

\[f_n = n \times f_0 \quad \text{where } n = 1, 2, 3, 4, \ldots\]

Each instrument produces these harmonics at different relative amplitudes. A flute is almost a pure sine (strong fundamental, weak harmonics). A violin has strong harmonics all the way up. An oboe has particularly strong odd harmonics.

This is exactly what the different oscillator types in p5.js are modeling:

  • Sine: only \(f_0\). No harmonics. Pure tone.
  • Triangle: odd harmonics (\(f_0, 3f_0, 5f_0, \ldots\)), each at amplitude \(\frac{1}{n^2}\). They fall off fast, so it's soft.
  • Square: odd harmonics at amplitude \(\frac{1}{n}\). Brighter than triangle.
  • Sawtooth: all harmonics (odd and even) at amplitude \(\frac{1}{n}\). The richest, brightest standard waveform.

Additive Synthesis: Building Timbre from Scratch

Since any periodic sound is a sum of sine waves (this is Fourier's theorem), we can build custom timbres by stacking sine oscillators at harmonic frequencies with chosen amplitudes. This technique is called additive synthesis.

open example in new window 
let oscillators = [];
let amplitudes = [0.35, 0.25, 0.15, 0.1, 0.06, 0.04];
let baseFreq = 220;
let env;
let playing = false;

function setup() {
  createCanvas(400, 300);

  for (let i = 0; i < amplitudes.length; i++) {
    let o = new p5.Oscillator('sine');
    o.freq(baseFreq * (i + 1));
    o.amp(0);
    o.start();
    oscillators.push(o);
  }

  env = new p5.Envelope();
  env.setADSR(0.01, 0.3, 0.4, 0.5);
  env.setRange(1.0, 0);

  textAlign(CENTER, CENTER);
  textSize(14);
}

function draw() {
  background(15);

  fill('#f0ece4');
  text('click to play:  6 harmonics stacked', width / 2, 20);

  for (let i = 0; i < amplitudes.length; i++) {
    let x = map(i, 0, amplitudes.length - 1, 60, width - 60);
    let h = amplitudes[i] * 400;
    noStroke();
    fill('#FF4D1C');
    rect(x - 15, height - 40 - h, 30, h);
    fill('#888');
    text('h' + (i + 1), x, height - 20);
  }
}

function mousePressed() {
  for (let i = 0; i < oscillators.length; i++) {
    oscillators[i].amp(amplitudes[i], 0.01);
  }
  env.play(oscillators[0]);

  setTimeout(function () {
    for (let i = 0; i < oscillators.length; i++) {
      oscillators[i].amp(0, 0.5);
    }
  }, 1500);
}

Here, harmonic 1 (the fundamental at 220 Hz) is the loudest, and each successive harmonic is quieter. Changing the amplitude ratios changes the timbre entirely: try making the 3rd harmonic dominant for a clarinet-like quality, or boost all harmonics equally for a harsh, buzzing sound.

This is the core insight: timbre is not a mysterious quality: it's a recipe. Every sound is a specific combination of sine waves at specific amplitudes. Additive synthesis makes that recipe explicit.

Layering Oscillators with Different Envelopes

One powerful technique is giving each oscillator its own envelope. The attack portion might emphasize higher harmonics (bright, percussive onset), while the sustain portion lets lower harmonics dominate (warm, mellow body). This mimics how real instruments behave: the initial bow scratch on a cello is spectrally very different from the sustained note that follows.

open example in new window 
let oscLow, oscHigh, envLow, envHigh;

function setup() {
  createCanvas(400, 300);

  oscLow = new p5.Oscillator('sine');
  oscHigh = new p5.Oscillator('sawtooth');
  oscLow.amp(0);
  oscHigh.amp(0);
  oscLow.start();
  oscHigh.start();

  envLow = new p5.Envelope();
  envLow.setADSR(0.3, 0.2, 0.5, 0.8);
  envLow.setRange(0.3, 0);

  envHigh = new p5.Envelope();
  envHigh.setADSR(0.005, 0.1, 0.0, 0.05);
  envHigh.setRange(0.15, 0);

  textAlign(CENTER, CENTER);
  textSize(14);
}

function draw() {
  background(15);
  fill('#f0ece4');
  text('click: percussive high + sustained low', width / 2, height / 2);
}

function mousePressed() {
  let f = random([110, 165, 220, 275, 330]);
  oscLow.freq(f);
  oscHigh.freq(f * 3);
  envLow.play(oscLow);
  envHigh.play(oscHigh);
}

The low sine oscillator swells in slowly and sustains: it provides the body. The high sawtooth oscillator has an almost instant attack and no sustain: it provides the percussive "click" at the start of the note. Together, they create a much more interesting and organic sound than either alone.
